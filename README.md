# Neon Dash: Overdrive 🚀

Welcome to **Neon Dash: Overdrive**, a fast-paced, neon-infused platformer built entirely with HTML5 Canvas, JavaScript, and Tailwind CSS. Dodge spikes, fly ships, and reverse gravity in this procedurally generated arcade game!

## 🎮 Play the Game
 https://pikachu-code-ai.github.io/Neon-dash/
 
## ✨ Features
*   **5 Difficulty Levels:** From "Easy" to "Impossible", each difficulty introduces new obstacle pools, faster speeds, and tighter gaps.
*   **Procedural Generation:** Every run feels fresh! Obstacles are procedurally generated using randomized configurations so no two levels are exactly the same.
*   **Multiple Game Modes:** 
    *   **Cube Mode:** Time your jumps to hop over spikes and saws. Hit Yellow Rings in mid-air for a double jump!
    *   **Ship Mode:** Hold the jump button to thrust upwards and release to fall, navigating tight tunnels.
    *   **Gravity Portals:** Flip the world upside down and run on the ceiling!
*   **Responsive & Cross-Platform:** Playable on desktop and mobile devices.
*   **Local High Scores:** Your best scores for each difficulty are automatically saved in your browser.

## 🕹️ Controls
*   **Jump:** Press `Spacebar`, `Left Click`, or `Tap` the screen.
*   **Ship Mode:** `Hold` Spacebar/Click/Tap to fly up, `Release` to fall.
*   **Mid-Air Rings:** Tap while intersecting a yellow ring to perform a mid-air jump.

## 🛠️ Tech Stack
*   **HTML5 Canvas:** For rendering the game world, entities, and particles.
*   **Vanilla JavaScript:** Core game loop, physics, collision detection, and procedural generation.
*   **Tailwind CSS:** For styling the beautiful, glass-morphic UI overlays and menus.
